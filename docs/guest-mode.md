# 游客模式：权限边界与数据同步

一句话：**记录不需要登录，跟人互动才需要。** 产品定位是个人私密成长平台，时间线只属于自己，论坛才是公开区。

## 两种状态

| | 游客（未登录） | 登录用户 |
| --- | --- | --- |
| 时间线 / 上传 / 成长报告 / 关于我 / 节拍器 | 全部可用，数据存本机 | 全部可用，记录云端同步 |
| 视频文件 | 只在本机（不上传） | 只在本机（不上传） |
| 舞友论坛 · 浏览 | 最近 3 条公开话题的标题与摘要 | 全部话题、回复、报名名单 |
| 发帖 / 回帖 / 点赞 / 报名约练 | 不可用（提示登录） | 可用 |
| 舞友（好友申请）/ 私信 | 不可用（提示登录） | 可用 |
| 换设备 | 数据不跟随 | 同号登录自动拉回 |

权限文案的唯一来源是 `src/utils/access.ts`（`ACCESS_ROWS` / `SYNC_NOTES`），UI 里不要再手写第二份。

## 视频只存本机（已知限制，不做跨设备同步）

视频原片体积大，暂不接入对象存储，**无论是否登录都只保存在上传时那台设备**。这不影响记录本身——云端同步的是标题、日期、标签、笔记，以及上传时抽帧生成的封面（JPEG dataURL），所以换设备后卡片仍然完整可读，缺的只有视频本体。

相关文案统一放在 `src/utils/videoNotice.ts`，四处引用，改一处全站一致：

| 常量 | 出现位置 | 作用 |
| --- | --- | --- |
| `VIDEO_BADGE_LOCAL` | 时间线视频卡片右上角 | 「仅存本机」轻标记，hover 显示全文 |
| `VIDEO_NOTE_LOCAL` | 播放器工具条下方、上传页预览框下方 | 常驻备注，播放时也看得见 |
| `VIDEO_UPLOAD_NOTICE` | 选好视频后的提示条 | 在上传当下就说清，避免用户误以为已上云 |
| `VIDEO_MISSING_TITLE/BODY/TIP` | 换设备点开、本机无原片时 | 致歉 + 给出两个出口（回原设备 / 重新上传） |

措辞原则：先说事实，再给替代方案，最后明确道歉；不出现「失败 / 丢失 / 失效」这类会让人以为数据没了的词。

## 数据存哪里、怎么同步

1. **游客期间**：所有写入走 IndexedDB（`cici_dance_diary_db`，媒体在 `cici_media_db`）与 localStorage，`sync.ts` 的 `queuePush` 因为 `currentUserId` 为空直接跳过，不产生任何云端请求。
2. **首次登录**：`isFirstBindOnDevice()` 判定这台设备还没绑定过账号 → 本地数据是游客自己记的，跟云端做**并集合并**（`mergeCollections`，同 id 以云端为准），而不是整表覆盖。合并结果立刻 `queuePush` 上云，并提示「已并入 N 条记录」。
3. **登录之后**：每次修改 0.7s 防抖推送；失败进重试队列；断网恢复自动补推。`syncAllDomains()` 在登录时做一次双向对账，补齐从未上过云的数据域（头像 / 标签 / 技能打卡等）。
4. **退出登录**：`signOut` 前先 `flush()`，本机数据保留。同设备登录另一个账号时 `prepareForUser()` 返回 `switched=true`，清空本机数据域，避免串号——游客数据不会被带进别人的账号。

## 交互约束

- 首次访问只弹一次「先以游客身份开始 / 登录」的选择（`cici_guest_welcome_seen_v1`），不再直接甩手机验证码。
- 游客态常驻一条提示条（可收起，`cici_guest_bar_hidden_v1` 仅本次会话有效），写明「已在本机存好 N 条，登录后自动并入」。
- 论坛只渲染 `threads.slice(0, GUEST_FORUM_PREVIEW_LIMIT)`，正文用 `previewText()` 截断并打码疑似联系方式；点任意卡片走 `LoginGateDialog`（先解释再给登录 / 继续游客两个出口），不直接弹验证码。
- 好友、私信两个页签沿用 `SocialViews` 里的 `LoginHint` 锁定态；线下联系人属本机数据，游客仍可用。

## 回归要点

- 375px：首屏 → 选游客 → 记录一条纯文字 → 刷新仍在、不再弹选择框。
- 论坛：卡片数 ≤ 3、无正文全文、点卡片出现「登录后查看完整帖子」。
- 导航：375 / 768 / 1024 / 1280 四档无标签重叠、无横向溢出（`Navbar` 的单行胶囊在 lg 才启用）。
