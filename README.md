# Cici's Jazz Diary | Cici的舞蹈成长日记与轻社区

普通 Jazz 舞蹈爱好者 Cici 的舞蹈成长记录与轻社区互动平台。
按时间线记录练舞历程、支持作品分类上传与舞友轻量互动交流，包含独创的 Jazz 8-Count 伴舞练习节拍器与慢速扒舞播放器。

---

## 🚀 本地运行指南 (Quick Start)

### 1. 安装项目依赖

在终端中进入解压后的项目目录，执行：

```bash
npm install
```

### 2. 启动本地开发服务器

```bash
npm run dev
```

启动后在浏览器中打开提示的本地地址（通常为 `http://localhost:3000`）。

### 3. 项目打包构建

```bash
npm run build
```

打包生成的文件将位于 `dist/` 目录下。

---

## 📁 核心功能模块

- **时间线（首页 Timeline）**：Cici 个人形象卡与打卡数据、多维舞种筛选 Chips、按时间倒序的作品卡片流、视频慢速扒舞（0.5x/0.75x）与镜面翻转模式。
- **上传作品（Upload）**：支持选择本地视频/图片或一键选用练舞示范预设、标题、日期、阶段（入门/进阶/挑战）、舞种多选、伴奏 BPM 与避坑小记。
- **找舞搭子 & 留言墙（Community）**：真实种子舞伴列表、关注联动、舞室约练弹窗、按分类筛选的气泡留言墙。
- **关于我（About Cici）**：Cici 小传、自动化多维数据统计看板、Recharts 过去四周练习活跃度折线走势图、16 周打卡热力图、Cici 私藏 Jazz 歌单、初学者技能树与数据备份导出。
- **Jazz 8-Count 节拍器**：Web Audio API 原生合成，第 1 和第 5 拍切分重音提醒，自由调节 65-140 BPM。
